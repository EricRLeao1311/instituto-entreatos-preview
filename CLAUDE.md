# Contexto de manutenção

Leia e siga [AGENTS.md](AGENTS.md) antes de alterar o projeto. Ele é a fonte única das instruções de trabalho para IA.

Para **toda alteração feita com IA**, siga o registro obrigatório de AGENTS.md e inclua a tarefa documentada no mesmo conjunto da mudança. Para backend ou hospedagem, consulte [docs/BACKEND-CLOUD.md](docs/BACKEND-CLOUD.md). O ambiente autorizado continua sendo teste.

Para mudanças editoriais, de menu ou de HTML/CSS, leia a política obrigatória de [preservação](docs/PRESERVACAO.md) indicada em AGENTS.md e execute os contratos de apresentação antes de concluir.

Para localizar arquivos de uma página, consulte [docs/MAPA-DE-EDICAO.md](docs/MAPA-DE-EDICAO.md). Para começar uma solicitação delimitada, copie [docs/tasks/TAREFA.md](docs/tasks/TAREFA.md).
